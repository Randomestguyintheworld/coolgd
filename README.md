# CoolGD

A small, original browser rhythm-platformer demo with three playable levels. It is inspired by the broad jump-and-dodge platformer genre, but uses original names, visuals, and level layouts—not Geometry Dash game content.

## Play

Open `index.html` in a browser. For local testing, you can also run `python3 -m http.server 8080` in this folder and visit `http://localhost:8080`.

Choose **Play level**, then use **Space**, **Up**, **W**, click, or tap to jump. Avoid the blocks and spikes, reach the end, and use **Restart** to try again. The game is a browser demo and does not include online multiplayer or a real leaderboard.
